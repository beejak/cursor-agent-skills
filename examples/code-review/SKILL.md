# Code Review

## Checklist

- [ ] Logic is correct and edge cases handled
- [ ] No security issues (injection, XSS, sensitive data)
- [ ] Matches project style and conventions
- [ ] Functions are focused; error handling is clear
- [ ] Tests cover the change

## Feedback format

- **Critical:** Must fix before merge
- **Suggestion:** Consider improving
- **Optional:** Nice to have
