# Skill checklist before you publish

Use this before you use or share a new skill.

## Core quality

- [ ] Description is specific and includes key terms
- [ ] Description includes both **WHAT** and **WHEN**
- [ ] Written in third person
- [ ] SKILL.md body is under 500 lines
- [ ] Consistent terminology throughout
- [ ] Examples are concrete, not abstract

## Structure

- [ ] File references are one level deep (no deep nesting)
- [ ] Progressive disclosure used where needed (link to reference.md, examples.md)
- [ ] Workflows have clear steps
- [ ] No time-sensitive information that will go stale

## If you include scripts

- [ ] Scripts solve the problem (not placeholders)
- [ ] Required packages are documented
- [ ] Error handling is explicit and helpful
- [ ] No Windows-style paths (use `scripts/helper.py`, not `scripts\helper.py`)
